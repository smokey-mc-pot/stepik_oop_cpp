# 2.4 Жизненный цикл объектов классов

## Создание и уничтожение объекта

На данный момент мы с вами в целом познакомились со способами создания объектов различных классов. При этом, как бы мы их ни создавали, все они формируются по единой схеме.

Давайте рассмотрим простой класс `Point`:

```cpp
class Point {
public:
    Point() : m_x{0}, m_y{0} {}
    Point(int a, int b) : m_x{a}, m_y{b} {}

    void get_coords(int& a, int& b) {
        a = m_x;
        b = m_y;
    }

    void set_coords(int a, int b) {
        m_x = a;
        m_y = b;
    }

private:
    int m_x{-1};
    int m_y{-1};
};
```

Его объекты можно создать следующими командами:

```cpp
int main() {
    Point pt1{};
    Point pt2{1, 2};
    Point* ptr_pt1 = new Point{};
    Point* ptr_pt2 = new Point{10, 20};

    delete ptr_pt1;
    delete ptr_pt2;

    return 0;
}
```

Что же стоит за словами «создание объекта» и его «уничтожение»? В действительности, все происходит по следующим этапам:

1. Выделение памяти под объект.
2. Инициализация переменных объекта.
3. Вызов конструктора объекта.
4. Жизнь объекта.
5. Вызов деструктора объекта.
6. Удаление переменных объекта: вызов их деструкторов, если это необходимо.
7. Освобождение памяти, занимаемой объектом.

Эти этапы выполняются для любых объектов класса, как бы мы их ни создавали, если речь идет о корректных способах создания.

## Порядок инициализации

После выделения памяти происходит инициализация переменных, и только после этого вызывается конструктор.

Инициализация переменных, прописанная в классе, выполняется до тела конструктора:

```cpp
class Point {
public:
    Point() : m_x{0}, m_y{0} {}
    Point(int a, int b) : m_x{a}, m_y{b} {}

private:
    int m_x{-1};
    int m_y{-1};
};
```

То же самое касается списка инициализации конструкторов:

```cpp
Point() : m_x{0}, m_y{0} {}
Point(int a, int b) : m_x{a}, m_y{b} {}
```

Переменные `m_x` и `m_y` инициализируются нулями или значениями `a` и `b`. Эта инициализация имеет более высокий приоритет, чем инициализация, записанная непосредственно возле полей класса.

То есть при создании объекта командой:

```cpp
Point pt{};
```

переменные `m_x` и `m_y` будут инициализированы нулями, а не значениями `-1`. Инициализация `-1` будет проигнорирована.

Инициализация, записанная в классе, является только значением по умолчанию. Она срабатывает при создании объекта класса, когда в самом объекте появляются переменные `m_x` и `m_y`. До этого они не существуют, а значит, не могут быть инициализированы.

## Объекты одних классов внутри другого класса

Следующий важный факт связан с использованием объектов одних классов внутри другого класса. Перед классом `Point` объявим еще один класс:

```cpp
class Log {
public:
    Log() {}
};
```

А в классе `Point` объявим объект класса `Log`:

```cpp
class Point {
public:
    Point() : m_x{0}, m_y{0} {}
    Point(int a, int b) : m_x{a}, m_y{b} {}

private:
    int m_x{-1};
    int m_y{-1};
    Log m_lg;
};
```

В каком порядке будут вызваны конструкторы этих классов?

Сначала будет создан объект `m_lg` и вызван конструктор класса `Log`, а затем вызван конструктор класса `Point`. Конструктор класса `Point` вызывается только после формирования всех переменных и объектов, описанных в этом классе.

## Инициализация вложенных объектов

Если в классе `Log` не будет конструктора по умолчанию, например:

```cpp
class Log {
public:
    Log(unsigned id_log) : m_id{id_log} {}

private:
    unsigned m_id{0};
};
```

то при создании объектов класса `Point` возникнет ошибка: объект `m_lg` невозможно сформировать без аргумента.

В этом случае нужно явно передать один аргумент при создании объекта `m_lg`. Это можно сделать непосредственно в классе:

```cpp
class Point {
public:
    Point() : m_x{0}, m_y{0} {}
    Point(int a, int b) : m_x{a}, m_y{b} {}

private:
    int m_x{-1};
    int m_y{-1};
    Log m_lg{5};
};
```

Или в списке инициализации соответствующих конструкторов:

```cpp
class Point {
public:
    Point() : m_x{0}, m_y{0}, m_lg{1} {}
    Point(int a, int b, unsigned id = 1) : m_x{a}, m_y{b}, m_lg{id} {}

private:
    int m_x{-1};
    int m_y{-1};
    Log m_lg;
};
```

Так как список инициализации имеет более высокий приоритет, объект `m_lg` будет создаваться с передачей одного аргумента и вызовом конструктора с одним параметром.

Важно помнить, что объекты и поля инициализируются в порядке их объявления в классе, а не в порядке записи в списке инициализации.

## Порядок вызова деструкторов

Деструкторы вызываются в обратном порядке: сначала вызывается деструктор объекта текущего класса, а затем деструкторы его полей и вложенных объектов. После этого освобождается память, занимаемая объектом.

Если объект был создан с помощью оператора `new`:

```cpp
Point* ptr_pt = new Point{};
```

то в конце нужно самостоятельно освободить память:

```cpp
delete ptr_pt;
```

Иначе память останется выделенной, но, скорее всего, больше не будет использоваться. Такая ситуация называется утечкой памяти.

Таким образом, жизненный цикл объекта состоит из последовательных этапов формирования, использования и уничтожения. Понимание этих этапов необходимо для грамотной работы с объектами классов в программах на C++.
