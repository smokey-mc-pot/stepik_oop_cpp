# 3.3 Перегрузка оператора присваивания

## Операция присваивания

Операция присваивания по умолчанию уже работает на уровне объектов любого класса и выполняет побайтное копирование содержимого одного объекта в другой. Но это не всегда является желаемым поведением.

В качестве примера рассмотрим реализацию известной структуры данных - динамического массива. Мы уже реализовывали ее в курсе по языку C. Здесь повторим эту структуру на уровне класса C++.

В основе динамического массива лежит обычный массив языка C. Его состояние можно определить двумя целочисленными переменными:

- `capacity` - физическая длина массива;
- `length` - количество записанных в массив данных.

Как только длина `length` достигает значения `capacity`, в памяти создается новый массив, часто удвоенной длины. В новый массив копируются данные из старого массива. В результате физическая длина массива автоматически увеличивается, и новые данные записываются уже в него.

## Класс DArray

Объявим класс `DArray` для работы с динамическим массивом в отдельном заголовочном файле `darray.h`:

```cpp
class DArray {
public:
    DArray() : m_length{0}, m_capacity{start_length_array} {
        m_data = new int[m_capacity];
    }

    DArray(const DArray& other) : m_length{other.m_length}, m_capacity{other.m_capacity} {
        m_data = new int[m_capacity];

        for (int i{0}; i < m_length; ++i) {
            m_data[i] = other.m_data[i];
        }
    }

    ~DArray() {
        delete[] m_data;
    }

    int size() const {
        return m_length;
    }

    int capacity_ar() const {
        return m_capacity;
    }

    const int* get_data() const {
        return m_data;
    }

    const DArray& operator=(const DArray& other);

    void push_back(int value);
    int pop_back();

private:
    enum {
        start_length_array = 8,       // начальная длина массива
        resize_factor = 2,            // множитель увеличения длины массива
        max_length_array = 30,        // максимальная длина массива
        value_error = 2123456789      // специальное значение ошибки
    };

    int* m_data{nullptr};
    int m_length{0};                  // число записанных значений
    int m_capacity{0};                // физический размер массива

    void resize_array(int new_size);
};
```

Так как каждый объект класса `DArray` формирует собственный массив `m_data`, необходимо переопределить:

- конструктор копирования;
- деструктор;
- операцию присваивания.

## Правило трех

В стандарте C++11 существует так называемое **правило трех**. Оно гласит: если в классе переопределяется хотя бы один из следующих методов, то следует явно переопределить и оставшиеся два:

- конструктор копирования;
- деструктор;
- оператор присваивания копированием.

Как правило, эти методы работают в связке. Класс `DArray` не является исключением: ему необходимо корректно определить все три элемента.

В более новых стандартах используется **правило пяти**. К трем перечисленным операциям добавляются:

- конструктор перемещения;
- оператор присваивания перемещением.

## Реализация методов

Реализацию операции присваивания и остальных методов разместим в файле `darray.cpp`:

```cpp
#include "darray.h"

void DArray::resize_array(int new_size) {
    if (new_size <= m_capacity) {
        return;
    }

    while (m_capacity < new_size) {
        m_capacity *= resize_factor;

        if (m_capacity >= max_length_array) {
            m_capacity = max_length_array;
            break;
        }
    }

    int* new_data = new int[m_capacity];

    for (int i{0}; i < m_length; ++i) {
        new_data[i] = m_data[i];
    }

    delete[] m_data;
    m_data = new_data;
}

const DArray& DArray::operator=(const DArray& other) {
    if (this == &other) {
        return *this;  // присваивание объекта самому себе
    }

    m_length = other.m_length;
    m_capacity = other.m_capacity;

    delete[] m_data;
    m_data = new int[m_capacity];

    for (int i{0}; i < m_length; ++i) {
        m_data[i] = other.m_data[i];
    }

    return *this;
}

void DArray::push_back(int value) {
    if (m_length >= m_capacity) {
        resize_array(m_capacity * resize_factor);
    }

    if (m_length < m_capacity) {
        m_data[m_length++] = value;
    }
}

int DArray::pop_back() {
    if (m_length > 0) {
        return m_data[--m_length];
    }

    return value_error;
}
```

Операция присваивания работает следующим образом: из присваиваемого объекта копируются все поля, затем для текущего объекта создается собственный массив `m_data`, в который копируются значения из другого объекта.

В начале оператора выполняется проверка на присваивание объекта самому себе. Формально можно написать:

```cpp
array = array;
```

Но такое присваивание не имеет смысла. Без проверки программа сначала удалила бы массив, а затем попыталась скопировать данные из уже удаленной памяти.

Операцию присваивания нельзя переопределить вне класса отдельной функцией, как это можно сделать с операцией сложения. `operator=` должен быть методом класса.

## Использование класса DArray

Полученный класс можно использовать следующим образом:

```cpp
#include <iostream>
#include "darray.h"

int main() {
    DArray array1{};
    DArray array2{};

    for (int i{0}; i < 10; ++i) {
        array1.push_back(i + 1);
    }

    array2 = array1;

    std::cout << array2.size() << " " << array2.capacity_ar() << std::endl;

    for (int i{0}; i < array2.size(); ++i) {
        std::cout << array2.get_data()[i] << " ";
    }

    return 0;
}
```

После выполнения `array2 = array1` объекты содержат одинаковые значения, но используют разные массивы в памяти.
