# 3.1 Перегрузка оператора сложения

## Перегрузка операторов для объектов класса

Давайте предположим, что у нас есть класс для представления времени:

```cpp
class TimeDay {
public:
    TimeDay() : m_time{0} {}

    TimeDay(unsigned char hours,
            unsigned char minutes,
            unsigned char seconds,
            unsigned int days = 0)
        : m_time{seconds + minutes * 60 + hours * 3600 + days * 86400} {}

    void get_time(unsigned int& days,
                  unsigned char& hours,
                  unsigned char& minutes,
                  unsigned char& seconds) const {
        seconds = m_time % 60;
        minutes = m_time / 60 % 60;
        hours = m_time / 3600 % 24;
        days = m_time / 86400;
    }

private:
    unsigned long m_time{0};
};
```

Время здесь раскладывается по дням, часам, минутам и секундам. В самом классе `TimeDay` хранится одно число `m_time` - время в секундах.

В функции `main` мы можем использовать этот класс, например, так:

```cpp
#include <cstdio>

int main() {
    TimeDay t1{10, 45, 13};
    TimeDay t2{4, 11, 50};

    unsigned int days{0};
    unsigned char hours{0};
    unsigned char minutes{0};
    unsigned char seconds{0};

    t1.get_time(days, hours, minutes, seconds);
    std::printf("%u: %02u:%02u:%02u", days, hours, minutes, seconds);

    return 0;
}
```

## Оператор сложения как метод класса

Предположим, что мы хотим складывать объекты этого класса:

```cpp
TimeDay result = t1 + t2;
```

Но операция сложения для объектов `TimeDay` не определена, поэтому компилятор выдаст ошибку. Мы можем добавить эту возможность и задать порядок выполнения операции сложения для наших объектов.

Для этого в классе объявляется специальный метод, имя которого состоит из ключевого слова `operator` и символа переопределяемой операции:

```cpp
class TimeDay {
public:
    const TimeDay& operator+(const TimeDay& right) const {}

private:
    unsigned long m_time{0};
};
```

В этом примере оператор имеет возвращаемый тип `const TimeDay&`, а параметр `right` также передается как константная ссылка.

Когда выполняется сложение:

```cpp
TimeDay result = t1 + t2;
```

компилятор автоматически подставляет вместо операции сложения вызов нашего метода. Текущий объект, из которого выполняется вызов, - это объект `t1`, а в параметр `right` передается объект `t2`. Возвращаемое значение копируется в переменную `result`.

То же сложение можно записать с явным вызовом метода-оператора:

```cpp
TimeDay result = t1.operator+(t2);
```

Таким образом, `operator+` - это обычный метод класса, который компилятор использует при вычислении операции сложения для объектов `TimeDay`.

## Реализация оператора сложения

Пропишем реализацию метода операции сложения:

```cpp
class TimeDay {
public:
    TimeDay() : m_time{0} {}

    TimeDay(unsigned long time) : m_time{time} {}

    TimeDay(unsigned char hours,
            unsigned char minutes,
            unsigned char seconds,
            unsigned int days = 0)
        : m_time{seconds + minutes * 60 + hours * 3600 + days * 86400} {}

    TimeDay operator+(const TimeDay& right) const {
        return TimeDay{m_time + right.m_time};
    }

private:
    unsigned long m_time{0};
};
```

Для удобства мы добавили конструктор с одним параметром. Такой конструктор называется конструктором преобразования. В данном случае он преобразует значение типа `unsigned long` в объект `TimeDay`.

Оператор возвращает копию объекта `TimeDay`, а не ссылку, потому что созданный внутри метода временный объект перестает существовать после завершения метода. Если вернуть ссылку, она будет указывать на уже несуществующий объект.

Это важно учитывать при использовании ссылок в параметрах и возвращаемых значениях: нужно быть уверенным, что объект будет существовать необходимое время.

Благодаря конструктору преобразования можно написать:

```cpp
TimeDay result = t1 + 10;
```

Здесь `10` воспринимается как целочисленный литерал типа `int`, а затем с помощью конструктора преобразования превращается в объект `TimeDay`. После этого вызывается метод `operator+`, и результат копируется в переменную `result`.

Копирование встроено для объектов классов и структур. Для этого вызывается конструктор копирования по умолчанию, который побайтно копирует данные из одного объекта в другой.

Метод `operator+` также может возвращать обычное число типа `unsigned long`:

```cpp
unsigned long operator+(const TimeDay& right) const {
    return m_time + right.m_time;
}
```

Тогда при инициализации объекта `result` это число сначала будет преобразовано во временный объект `TimeDay`, а затем с ним будет вызван конструктор копирования.

## Ограничение оператора-метода

Обратите внимание: если поменять операнды местами:

```cpp
TimeDay result = 10 + t1;
```

возникнет ошибка компиляции. В этом случае метод `operator+` должен был бы вызываться через объект типа `int`:

```cpp
TimeDay result = 10.operator+(t1);
```

Но у объекта типа `int` такого метода нет.

## Оператор сложения как внешняя функция

Выйти из этой ситуации можно, если определить операцию сложения в виде внешней функции, а не метода класса:

```cpp
unsigned long operator+(const TimeDay& left, const TimeDay& right) {
    return left.get_time() + right.get_time();
}
```

Для этого в класс `TimeDay` нужно добавить метод `get_time`:

```cpp
unsigned long get_time() const {
    return m_time;
}
```

Компилятор автоматически выберет подходящую функцию для операции сложения и подставит ее вызов.

Однако может возникнуть конфликт, если оператор объявлен и как метод класса, и как отдельная функция. Например, при выражении:

```cpp
TimeDay result = t1 + 10;
```

возникает неопределенность: какой из двух вариантов использовать?

Поэтому операции следует переопределять либо методами, либо внешними функциями.

Внешние функции особенно полезны, когда требуется определить операции для объектов уже существующих классов, которые нельзя редактировать напрямую. В такой ситуации внешняя функция может быть единственной возможностью переопределить стандартную операцию.
